Daily Time Budget
-----------------

Each lab day runs for **3 hours** structured as follows:

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - Block
     - Content
   * - 0:00 – 1:00
     - Theory lecture (slides + whiteboard + live demos by instructor)
   * - 1:00 – 3:00
     - Guided lab exercises (students work, instructors circulate)
   * - (fast finishers)
     - Bonus / stretch exercises at the end of each day

Hackathon Overview (Day 5)
--------------------------

The final day is a **full-day open hackathon**.  Student teams use the hardware and
kernel knowledge built over Days 1–4 to implement a small retro game on the
i.MX93 FRDM board.

Available hardware:

- **3 LEDs** connected via GPIO (status indicators or game feedback)
- **4 push-buttons** connected via GPIO with interrupt-driven input
- **BMP280** temperature/pressure sensor via I2C
- **ST7789** 240×240 TFT display via SPI

Suggested game ideas: Pong, Snake, Breakout, or Tetris.  Teams present a
5-minute live demo at the end of the day.
